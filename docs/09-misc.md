# 九、支持情况与杂项

[返回文档首页](../README.md)

> 最后验证日期：2026-07-29。GitHub平台能力可能更新，使用前应结合目标页面的实际预览和官方文档确认。

## 9.1 GitHub平台的常见限制

截至上述验证日期，GitHub文档渲染不提供以下能力：

- 自定义CSS样式表和任意JavaScript执行。
- 通过`<script>`、`<iframe>`等标签嵌入可执行内容。
- 为围栏代码块启用内置行号，或通过Markdown语法控制自动换行策略。
- 将音频附件直接渲染为原生音频播放器。
- 完整的LaTeX文档环境、宏包加载、公式交叉引用和稳定的自动编号。

GitHub允许部分原始HTML，但最终输出会经过安全过滤。标签能够写入源码，不代表属性、样式和嵌入内容一定会保留。

还需要区分“语法受支持”和“在所有位置都受支持”：仓库中的Markdown文件、README、Wiki、Issue、Pull Request、Discussion和评论并不一定具有完全相同的上传、交互和渲染能力。文档没有明确保证全部位置时，应按目标页面实际预览，不要从一个页面的结果推断所有页面。

## 9.2 功能归属与支持矩阵

符号说明：

- ✅：该层次直接定义或由GitHub明确提供。
- ⚠️：可以使用，但存在渲染器差异、安全过滤或页面范围限制。
- ❌：该层次不提供此能力。

| 功能 | CommonMark | 正式GFM扩展 | GitHub平台 | HTML后备方案 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 标题、段落、强调、引用 | ✅ | 继承 | ✅ | ⚠️ | 优先使用Markdown原生语法。 |
| 删除线 | ❌ | ✅ | ✅ | `<del>`、`<s>` | 正式GFM扩展。 |
| 表格 | ❌ | ✅ | ✅ | `<table>` | 正式GFM扩展。 |
| 任务列表项 | ❌ | ✅ | ✅ | 不建议手写`<input>` | 正式GFM定义任务列表项，GitHub提供交互和Issue集成。 |
| 扩展自动链接 | ❌ | ✅ | ✅ | `<a>` | 正式GFM扩展，可识别部分裸URL和邮箱。 |
| 脚注 | ❌ | ❌ | ✅ | 锚点链接 | 属于GitHub平台功能，不属于正式GFM。 |
| Alerts | ❌ | ❌ | ✅ | 块引用 | 属于GitHub平台功能。 |
| 数学公式 | ❌ | ❌ | ✅ | 不适用 | 支持范围不是完整LaTeX环境。 |
| Mermaid图表 | ❌ | ❌ | ✅ | 图片 | 属于GitHub平台功能。 |
| GeoJSON、TopoJSON、STL | ❌ | ❌ | ✅ | 图片或附件 | 仅在GitHub支持的页面位置渲染。 |
| 行内代码和代码块 | ✅ | 继承 | ✅ | `<code>`、`<pre>` | 语言标识符可启用语法高亮。 |
| 下标和上标 | ❌ | ❌ | ⚠️ | `<sub>`、`<sup>` | HTML会经过GitHub安全过滤。 |
| 折叠区域 | ❌ | ❌ | ⚠️ | `<details>`、`<summary>` | 属于允许的HTML用法，不是Markdown或GFM语法。 |
| 字体和背景颜色 | ❌ | ❌ | ❌ | 不可靠 | GitHub不支持自定义CSS，不应依赖`style`或过时的`<font>`标签。 |
| 图片 | ✅ | 继承 | ✅ | `<img>` | 建议提供有意义的替代文本。 |
| 视频附件 | ❌ | ❌ | ⚠️ | 不可靠 | GitHub附件功能可在受支持上下文中展示视频，不属于GFM；原始`<video>`不可靠。 |
| 音频附件 | ❌ | ❌ | ⚠️ | 不可靠 | 仅部分上传上下文接受音频，通常以附件链接提供；原始`<audio>`不可靠。 |

## 9.3 判断一项语法属于哪一层

遇到新的Markdown写法时，可以按照以下顺序判断：

1. 在CommonMark规范中查找基础语法定义。
2. 在GFM规范的扩展章节中确认是否属于正式GFM。
3. 在GitHub写作文档中确认是否属于GitHub平台功能。
4. 如果使用HTML，确认GitHub是否保留相关标签和属性。
5. 在Issue、Pull Request、README等目标位置进行实际预览。

官方参考：

- GFM规范：<https://github.github.com/gfm/>
- CommonMark规范：<https://commonmark.org/>
- GitHub写作文档：<https://docs.github.com/get-started/writing-on-github>

## 9.4 HTML 注释

HTML 注释使用 `<!-- -->` 语法，注释内容不会显示在页面正文中。

> **警告**：注释源码仍然可见，不要在注释中写入密钥、Token 或其他敏感信息。

案例：

```markdown
<!-- 这是注释，不会显示在页面正文中 -->
这是一段普通文本
```

显示效果如下：

> <!-- 这是注释，不会显示在页面正文中 -->
> 这是一段普通文本

<br/>

## 9.5 `<kbd>` 快捷键标签

`<kbd>` 标签用于表示键盘按键或快捷键，常见于 GitHub README 中。

> **注意**：`<kbd>` 是 HTML 标签，不是 Markdown 或 GFM 原生语法，渲染效果因平台而异。

案例：

```markdown
按 <kbd>Ctrl</kbd> + <kbd>C</kbd> 复制
```

显示效果如下：

> 按 <kbd>Ctrl</kbd> + <kbd>C</kbd> 复制

<br/>

## 9.6 定义列表

定义列表是一种术语和定义对应的格式，但定义列表不是 CommonMark 或正式 GFM 语法，部分编辑器支持。

> **警告**：GitHub 不支持定义列表语法，不应依赖此语法编写面向 GitHub 的文档。

案例：

```markdown
术语
: 定义内容
```

该语法在支持它的编辑器中可能渲染为：

> **术语**
> : 定义内容

第三方编辑器扩展可能在不同平台有不同行为，编写文档时应优先使用普通段落或表格。
